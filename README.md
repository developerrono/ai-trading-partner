# RONO AI Trading Partner

Build "RONO AI Trading Partner"

Create a modern, premium, responsive web application called RONO AI Trading Partner.

This application is a personal AI trading workspace designed for a single trader. It is NOT a broker, trading platform, or signal service. It functions as an intelligent trading partner that helps prepare, monitor, analyze, and review trades.
